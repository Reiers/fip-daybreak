# FIP Daybreak

**FIP-XXXX: Daybreak — Sector Parity, Reserve Cleanup, and Economic Simplification**

> *A comprehensive economic rebalancing proposal for Filecoin.*

## What This Is

A draft FIP that consolidates years of community proposals (FIP-0078, FIP-0080, FIP-0093, Discussion #972) into a single, implementation-ready specification.

## Four Coordinated Changes

1. **Sector Parity**: Reduce verified deal multiplier 10x → 5x → 2.5x → 1.25x → 1x over 12 months
2. **Reserve Cleanup**: Burn ~282.9M FIL mining reserve (f090 → f099)
3. **CC Offboarding**: Zero termination fee for CC sectors + 7-day pledge lockup
4. **Baseline Recalibration**: Reduce baseline growth from 100%/year to 50%/year
